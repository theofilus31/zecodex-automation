ZECODEX Automation

A private tool for the ZECODEX YouTube channel

ZECODEX Automation is an internal, single-user tool used by the owner of the ZECODEX YouTube channel (Marvel movie facts Shorts). It is not offered to the public and has no other users.

What it does

  • Reads the channel's own YouTube Analytics (views, watch time, audience country) to plan content.
  • Uploads Shorts to the owner's own channel, and only after the owner has manually approved each video.
  • Reads public YouTube search data to spot trending Marvel topics.

The tool runs only on the owner's own computer. It uses YouTube API Services.
